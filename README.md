# Cooling Cabinet Controller

Arduino-based cooling cabinet control system developed in C++.

## Overview

The project demonstrates basic industrial-style temperature monitoring and cooling control.

- Temperature monitoring
- Automatic fan control
- Alarm handling
- LCD status display
- Modbus RTU communication
- Rapid SCADA integration for monitoring and control

## Technologies

- Arduino
- C++
- Modbus RTU
- Rapid SCADA
